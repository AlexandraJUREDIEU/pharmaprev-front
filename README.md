# Pharmaprev - Frontend

Interface utilisateur de l’outil de tarification d’assurance **Pharmaprev**.

## 🚀 Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS v4
- shadcn/ui (basé sur Radix UI)
- Zustand (à venir)

## 📦 Installation

```bash
npm install
npm run dev
```

## 📁 Structure (à venir)

```css
src/
├── components/
├── pages/
├── store/
└── ...
```

## 📌 Branches principales

`main` : branche stable pour prod
`dev` : branche de développement
`feat/*` : branches fonctionnelles
